# Sephora Skincare Reviews: Rating vs Sentiment Analysis

## About
This project analyzes whether customer ratings on Sephora skincare products actually match what they write in their reviews. Sometimes people give 5 stars but complain in the text, or give 1 star while writing something positive. I wanted to find these mismatches and see how they differ across product types like moisturizers, cleansers, serums, etc.

This is my term project for DSA 210 (Introduction to Data Science) at Sabancı University, Spring 2026.

## Dataset
I used the [Sephora Products and Skincare Reviews](https://www.kaggle.com/datasets/nadyinky/sephora-products-and-skincare-reviews) dataset from Kaggle. The full dataset has ~8,000 products and ~1 million reviews. Since the full data was too large to process efficiently (especially for sentiment analysis), I filtered it down to 6 main skincare subcategories and took a random sample of 60,000 reviews.

The 6 subcategories I focused on: Moisturizers, Treatments, Cleansers, Eye Care, Masks, Sunscreen.

## What I Did So Far

### Phase 2: Data Collection, EDA & Hypothesis Tests (April 14)

**Data preparation:**
- Merged 5 separate review CSV files (~1.09M reviews total)
- Filtered to skincare products only using product_info.csv
- Sampled 60,000 reviews for computational feasibility

**Feature engineering:**
- Computed VADER sentiment scores for each review
- Labeled reviews as Positive, Negative, or Neutral based on compound score
- Created a mismatch flag (e.g. high rating but negative text)
- Added price segments: Budget (≤$25), Mid-range ($25-$60), Luxury (>$60)
- Calculated review length (word count)

**EDA highlights:**
- ~89.5% of reviews are positive, only 7.7% negative
- Cleansers get the highest 5-star rate (66.9%), Eye Care the lowest (56.7%)
- About 8.8% of reviews have a rating-sentiment mismatch
- Treatments have the highest mismatch rate among all subcategories
- Luxury products get slightly higher ratings than budget ones

**Hypothesis tests:**
| Test | Method | p-value | Result |
|------|--------|---------|--------|
| Ratings differ across subcategories | One-Way ANOVA | < 0.001 | Significant |
| Moisturizers vs Treatments ratings | T-Test | 0.48 | Not significant |
| Sentiment differs across subcategories | One-Way ANOVA | < 0.001 | Significant |
| Mismatch depends on subcategory | Chi-Square | < 0.001 | Significant |
| Budget vs Luxury ratings | T-Test | < 0.001 | Significant |

## How to Run
1. Download the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python EDA_and_Hypothesis_Tests.py`

The script will display 8 figures and print all hypothesis test results to the terminal. Figures are also saved to the `figures/` folder.
