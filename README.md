# DSA 210 Term Project

This repository contains my individual term project for DSA 210 Introduction to Data Science, Spring 2025-2026.

## Project Topic
Analyzing Consumer Satisfaction in Online Beauty Product Reviews

## Project Motivation
This project aims to explore the factors that influence consumer satisfaction in online beauty product reviews. By analyzing ratings, review text, and product-related variables, the study will investigate patterns in customer preferences and online review behavior.

## Planned Workflow
- Data collection
- Data cleaning and preprocessing
- Exploratory data analysis
- Hypothesis testing
- Machine learning applications
- Final report and visualizations

## Repository Structure
- `data/`: raw and processed datasets
- `notebooks/`: Jupyter notebooks
- `src/`: Python scripts
- `proposal/`: proposal document
- `reports/`: final report
